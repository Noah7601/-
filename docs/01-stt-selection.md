# STEP 1 — STT 엔진 선정

## 결론 (확정, v2 — 사용자 결정 반영)
**V1 STT: Soniox** (사용자 보유 API 키 활용, 2026-09-14 확정)

근거: 자체 벤치마크 기준 한국어 WER 4.3%(OpenAI 10.8% 대비 우수 — ⚠️ Soniox 자체 발표 수치, 독립검증 아님), 화자분리·timestamp·언어감지가 **추가 과금 없이 기본 요금에 포함**, async $0.10/시간으로 RTZR 대비 훨씬 저렴, API 키 보유로 즉시 착수 가능(계정/결제 절차 불필요).

**1차 조사 당시 추천이었던 RTZR은 기각** — 사유: 국내리전 처리라는 장점은 있으나, 사용자가 Soniox API 키를 이미 보유해 진입장벽이 없고 가격도 더 낮음. 아키텍처상 STT는 Transcript 계층만 잘 저장하면 교체 비용이 낮으므로(4계층 분리 원칙), 지금은 보유 키로 빠르게 MVP를 검증하는 쪽이 합리적.

**차선(백업/비교 대상): Naver Clova Speech Recognition (CSR)**
정확도 근접(상담 시나리오 4.91% CER), 화자분리(`speakerCountMin/Max`)·timestamp 지원, 국내 리전. 단가 확인 안 됨(콘솔 로그인 필요) → 향후 Soniox 실측 결과가 기준 미달이면 대체 후보로 재검토.

**제외: OpenAI Whisper/gpt-4o-transcribe, Google Cloud STT, Deepgram**
사유는 아래 비교표 참조. Deepgram은 한국어가 code-switching 지원 언어 목록에 없어 1차 제외.

## 왜 Soniox인가 (근거)
1. **진입장벽 없음** — 사용자가 이미 API 키 보유 → 계정/결제 절차 없이 바로 MVP 테스트 가능.
2. **가격 우위** — async $0.10/시간, 화자분리·timestamp·언어감지가 추가 과금 없이 기본 포함. RTZR 대비 훨씬 저렴.
3. **한국어 정확도 주장치가 경쟁력 있음** — Soniox 자체 60개 언어 벤치마크에서 WER 4.3%(OpenAI 10.8% 대비 우수) 주장. 단, 자사 발표 수치라 **독립 검증 필요**(아래 리스크 참조).
4. **아키텍처상 리스크가 낮음** — 4계층 분리 원칙(Source/Transcript/Intelligence/Ledger)에 따라 STT는 교체 비용이 낮은 구성요소. 지금 Soniox로 빠르게 시작하고, 실측 결과가 기준 미달이면 Naver Clova로 손쉽게 교체 가능.

## 리스크 / 미검증 항목 (⚠️ — 계약/스케일업 전 필수 확인)
- ⚠️ **정확도 수치가 Soniox 자체 발표** — 독립 벤치마크 아님. AI-Hub 등 제3자 기준 한국어 CER/WER 비교 자료 없음 → **RTZR(CER 5.91%, 제3자 벤치마크)이 여전히 더 신뢰도 높은 수치**. MVP 1차 테스트에서 동일 PLAUD 녹음으로 Soniox 실제 전사 품질을 사람이 직접 검수해야 함.
- ⚠️ **데이터가 국내가 아닌 해외(미국)에서 처리됨** — 영업 제안가·고객 정보 등 민감한 비즈니스 대화가 많은 프로젝트 특성상 개인정보/영업비밀 처리 정책을 확인해야 함(Soniox 데이터 보관·재사용 정책 미검증).
- ⚠️ 긴 오디오(1시간 이상 회의) 처리 시 파일 크기/길이 제한 — 네트워크 제약으로 공식 문서(`soniox.com/docs`) 원문을 직접 열람하지 못했다. **미검증, 계약 전 확인 필요**.
- ⚠️ 한/영 혼합 발화 정확도 벤치마크 없음 → 실측 필요.
